# Tessera: overview

Tessera is a file-sync and sharing tool for small teams. It first shipped in March 2024. The current release is version 2.4.

- Tessera syncs a shared folder across all of a user's devices. There is no limit on the number of devices per user.
- Files are encrypted end to end on every plan.
- The Team plan costs $8 per user per month, billed monthly.
- Version history keeps every file version for 30 days.
- Admins manage users from a web console.
