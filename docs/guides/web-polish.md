# Node guide: web polish (unit web-polish)

Read with docs/guides/common.md: its rule [stale-state] covers the picker, the tests card and the unit toggle (same node, scroll, focus and selection survive every snapshot; test on a DOM, not by regex). The spec (items 1-15) is in the node task; this file says what binds, what you may break, where it is easy to go wrong, and how to check. Tests are named, not numbered by line.

## Rules that bind
- docs/contract.md, intro: "wfviz is universal"; no role, phase, label, node code, file name or result shape of our method "may be required or hard-coded" in src/, web/, bin/. test/integration/universal.test.mjs skips lines that start with // and block comments, and a trailing comment counts, so item 11 needs its own scan.
- contract §1 Replay: "the server runs in mode `replay`, `hello` carries it, and the UI shows a REPLAY banner (never REAL, never DEMO)"; shown times are the run's own ("ts included"). §2: "Every value the UI shows is a **Fact**"; `source: "real" | "demo" | "replay"`.
- contract §4: `run` snapshots "at most once per second per run"; `seq` "per run, from 1, no gaps"; "The UI animates and logs from `event`, not from snapshot differences"; the backlog is the "last 2000". §4 is stale and not yours (say so in the note): it lists hello `mode: "real" | "demo"` and a run list without `source`, while the server sends "replay" and the list item has `source` (src/model/reduce.mjs summaryOf).
- AGENTS.md, Hard rules: "Never invent data. A value the source does not provide stays `unknown` with a reason."; "Roles, phases and labels come from run data, never hard-coded."; "The visualizer only observes"; "Write only the files your node owns."; no git commit, stash or reset; zero npm dependencies. "Images and video": read pages as DOM text; never use the browser pane.
- graph.md §9 and AGENTS.md Learned rules: "A node's gate can block on a test outside its owned paths that asserts the old contract; the fixer cannot touch it. Give the node the shared tests it invalidates, or the orchestrator fixes them right after." Only high and medium findings send work back.

- Will fail: web-u3 "every list is a keyed list; the only inner-HTML writes..." lists four allowed writes, one is the `<select>` line with `state.selectHtml` (item 8).

- Stay, web-lib timers: "nothing is re-rendered on a timer" counts exactly one `setInterval(` and two `setTimeout(`, and wants `setInterval(tick, 1000)` and `clearInterval(state.clock)`: add no timer. "a snapshot times the log lines again" wants the literal calls `logOrder(state.log.lines, state.run, state.backlogSeq)`, `retimedLines(state.log.lines, state.run,` and `'data-tkey': l.timeKey`. "the log is the bottom pane" reads the first `.log-pane {`, `.log {` and `body {` blocks: add no earlier rule for them.

- The web-u3 fake browser (PageEl) has no focus, contains, activeElement, createTextNode, createDocumentFragment or children; querySelector gives null and querySelectorAll gives []. Boot and the SSE path must run on it: use other DOM calls only on user input, or guarded (`el.focus?.()`).

## Traps
- Picker, inventing. A row comes from the list item only. `startedAt`, `name`, `status` are Facts: `val()`, else "?" with the reason. `agents` and `source` can be missing (the web-u3 list items have neither, and the SSE handler builds a summary without them): show "?", never 0, never the hello mode. When a `run` updates a row take them from the snapshot (`run.totals.agents`, `run.totals.running`, `run.source`).
- Picker, text. "(no name)" is a placeholder, so search must not match it. `fmtTime` shows no date: decide for a replay of an old run, name it. Format in app.js, so lib tests do not depend on locale or time zone.
- Elapsed (item 15). Measured on wf_6509ce25-20a: `durationMs` 13408, start 1794126711269, yet journal event seq 1 has ts 1794127828009 (+1.12e6 ms, 18.6 min), because journal lines carry the file time (contract §1: "else file mtime"). "Last event ts" as the end is wrong from the first event: decide where it comes from (recommended: the Run's `endedAt`, else `latestRecorded(run)`), name the deviation, test with such events.
- Elapsed, clock. No `Date.now()` for replay or final (two equal snapshots must write nothing). `clockTick` tests `prov === 'inferred'`, and the new own-time Fact is inferred too, so decide by `source === 'real'` and a running status. Leave `countsFromNow` alone: `barEnd` uses it.
- Replay banner (item 2). Do not reuse the DEMO banner text or style ("synthetic"): replay is real data. Whitelist `hello.mode`; never put it raw into `className` (today `badge ${h.mode}`); never fall through to REAL for an unknown mode. Say nothing of speed or path (hello has neither). Add `.badge.replay` from tokens.
- Log count (item 3). `createEventLog.trim` and `renderLogCount` count lines including `{missing, from, to}` markers. Count events only, in the header and in the cap; decide what a marker with no event before it does; test with markers.
- Log notice (item 4). Keys: marker `['missing', from]`, line `['seq', n]`, the notice its own key, first in order, never counted, never sorted (`logOrder` takes `state.log.lines` only), present in every `lists.log.sync`, removed on success (`appendItems` only appends; `appendLog` compares item counts). The placeholder is `.log:empty::before`, so a child line hides it. `.log-pane.collapsed .log-notice { display: none }` is why the notice vanishes: give the header its own text.
- Log retry. Keep the `state.refetching` flag and the run token; add no timer or backoff. Selecting the current row again never fired on the native select: decide (recommended: retry when `backlogError` is set) and name it.
- Gap (item 5). Only the first backlog sets `state.backlogSeq`. Moving it to `state.log.last` re-sorts the live lines shown after the first backlog too; merging only the new batch is the other reading. Decide, test, name; move only elements that must move; keep the `isNearBottom` scroll rule.
- Round heading (item 6). Fix the heading, not `roundHistory`: today `esc(g.title)` plus a small " round unknown" for every group that is not round-known, so the neither group says it twice. A tag group keeps its small ("#r1 round unknown"). Pure function, tested.
- Flicker (item 7). `grep -n "innerHTML\|setHtml(" web/app.js` shows what is left: `#tl-axis` (changes each snapshot while a bar ends now), the `.hist` panel (a whole unit history in one spec), `.mrow-label` (holds the toggle), the hover panel, lane heads, `#report`, `#log-meta`. Make each keyed children or a text write, or name it in the note as a guarded one-string box.
- Flicker, test. A move re-inserts a node and restarts its CSS animation (`slidein` on `.acard` and `.fcard`; browser behaviour, left to the ui-check): keep moves minimal. Run the real app.js on a fake DOM, snapshots from `reduceRun` over `readRunDir` of the fixture, and count `writes` per element.
- Picker, structure. A keyed list (`listOf`), rows keyed by run id, no new innerHTML line. Use `data-run`, never `data-agent`, `data-unit`, `data-view`: the document click handler matches those. The global Escape handler closes the drawer: handle Escape in the picker first. `specOf` drops `false` attributes: pass `String(open)` for `aria-expanded` and `aria-selected`.
- Picker, listeners. One document listener for outside clicks, added at boot, not per open. No `setTimeout` for blur (use `focusout` with `relatedTarget`). Ignore Enter while `e.isComposing`. The highlighted row is kept by run id, not index, so an inserted row, a status change, a snapshot or typing keeps open state, search text, list scroll and focus.
- Search (item 9). A pure function returns segments; the page escapes each and wraps the match in `<mark>`. Never regex-replace into HTML, never treat the query as a regex. Lower-casing can change length (`'İ'.toLowerCase().length` is 2), so offsets from the lowered text break: test it. "no run matches" only when runs exist; an empty list says "no runs yet". Style `mark`, `input`, `button` from tokens (`font: inherit`).
- Live list (item 10). `loadRuns` assigns `state.runs` after the await and drops a row an SSE `run` added meanwhile. In replay `/api/runs` is `[]` until the first page connects, so that run arrives only by SSE: merge by id, newest data wins. Only `!state.runId` lets a `run` select; no other list update may call `selectRun`. Rows do not reorder on a status change (decide the order, name it).
- Universality (item 11). `roleColor` maps an unknown role with `(i < 0 ? 5 : i)`, the index of `--other` in the old PALETTE: fix the index with the new array. Name tokens by function: `--accent` for logo, active step, `.card.spot`, `.lane.active`, `.colspot`, flash fallback; `--c1..--c9` for roles; `--other` for no role.
- Verdict tag. Today `class="tag ${esc(vv(v))}"` puts a verdict value in a class: "pass" or "running" takes state colours, a value with a space adds classes. Use a neutral `.tag` and a slot per distinct value in order of appearance (pure function).
- Scan test. Split names on `-` and `_` and compare whole tokens (impl, rev, judge, fix, test, accept, implement, review, reviewer, fixer), so `.tests-row`, `#tests`, `.fcard`, `--fail` pass; prove it flags `--judge`, `.tag.accept`, `var(--impl)`, `'--rev'` in css, js strings and html. Also scan comments for `Node U\d`, `(item N)`, `\bU\d\b`: lib.js has ten.
- Scrollbars (item 1). style.css has one dark `:root` palette, no light theme, no `prefers-color-scheme`, no toggle: do not invent one. Use only `var(--…)` in scrollbar rules, no hex, so any theme that sets the tokens is followed; name that reading. Scrollers: `.col`, `.steps`, `.lanes`, `.log`, `.drawer`, `.drawer pre`, `.report .err-more pre`, `.dblock pre`, `.grid` under 1100 px, the picker list. Not checked here: `scrollbar-color` is inherited and `scrollbar-width` is not; recent Chrome ignores `::-webkit-scrollbar` once `scrollbar-color` is set.
- Layout (items 12, 14). A role name is a bare text node in a flex row: wrap it in a span with `min-width: 0; overflow-wrap: anywhere`, keep `esc(r)`. Item 14: add a new function for `{rows, shown, total}`, leave `testRows`; M is `recognized.tests.length`; expand state is reset in `selectRun`; the button is keyed; older rows keep their keys.
- Focus (item 13). The toggle sits in the label string, so `updateSpecEl` rewrites the label and replaces the button when `open` or a tag changes. Make the label a group (`groupOf`, `createNode`, `updateNode`, as the drawer), the button its own keyed child with a raw `data-unit` (attrs are raw; `esc` would show `&amp;`). `lists.grid` uses `makeEl` and `updateSpecEl`: give it handlers that accept groups and still call `paintFlashEl` for new cells.

## How to check each item by hand
Start `node bin/wfviz.mjs --no-open --port 0 --idle 0 --replay wf_6509ce25-20a --root fixtures/claude-projects --speed 20`; the replay starts when the first page connects, and `curl -sN --max-time 3 "$URL/api/stream"` is that page (this Mac has no `timeout`). Read by curl, `node -e` over web/lib.js and the fake-DOM tests. Paint (scrollbars, dropdown look, focus ring) is for the orchestrator's ui-check: list it as unchecked.
1. `grep -n "scrollbar" web/style.css` covers every scroller above; no hex in those rules.
2. The first SSE frame has `"mode":"replay"`. On the fake DOM hello gives REPLAY, the banner shown, title "wfviz — REPLAY"; "real" and "demo" give REAL, DEMO, "wfviz", "wfviz — DEMO".
3. Events seq 1-2060 with seq 100-109 missing (one marker): the header says "showing the last 2000 of 2060 events"; with 1990 events it says 1990.
4. Fake fetch answers 500 on events: a line in `#log`, no placeholder, header text with the pane collapsed; one live event, or selecting the run, makes one request; success removes both.
5. Events 1-10 shown, live 15, gap batch 11-14 with earlier displayed times: the order equals `logOrder`.
6. A unit with an agent that has neither round nor tag: one "round unknown" in its heading.
7. Feed the replay's snapshots and events to the fake page: per event only that agent's elements, one log line and the counters are written; every other element has 0 writes. List the remaining `innerHTML` lines in the note.
8-10. Fake page: a row shows name or id "(no name)", status, start, agents, source ("?" when missing); arrows, Enter, Escape (the drawer stays), outside click; typing filters and marks; a `run` for a new id adds a row, a changed status updates it, `state.runId` is unchanged, timers and listeners do not grow.
11. The scan test is red on a planted `--judge` and green on the tree; `grep -n "Node U\|(item" web/` is empty.
12. A hand-built Run with 15 roles and a 40-character role: `.col` keeps `overflow-x: auto`, the role text wraps.
13. Toggle twice, then take a snapshot: the button is the same object with no extra write.
14. 12 test rows: "showing 8 of 12"; expanding shows 12 and leaves the first 8 untouched.
15. Replay mid-run and final: elapsed equals the run's own times and `timers.intervals.size` is 0; a running real run has one interval.
Before finishing run `node --test test/` once: all pass, 0 skipped (the orchestrator edits the shared tests named above).
