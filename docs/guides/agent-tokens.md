# Node guide: agent tokens (unit agent-tokens, P2)

Read with docs/guides/common.md; [stale-test], [stale-doc], [stale-state], [flicker], [weak-test], [guide-defect] apply. ASCII only. Start wfviz only with --no-open, stop it only by `kill <pid>`; no browser pane. No test touches the network (one real GET of the public list by hand is allowed, never in a test).

## Rules that bind
- Contract section 2: Agent.usage is "{ input, output, cacheRead, cacheWrite } summed over the agent's transcript usage records, one per API message (a message repeated in several records counts once); method names the dedup key; unknown with reason when no record has usage. Cost is never in the Run". totals.usage is "sum of the agents' usage values (same four keys); unknown if no agent has one"; totals.byModel is "{ [model id as the transcript gives it]: usage } (inferred, method "sum by transcript model")". Agent.tokens and totals.tokens stay (method `latest-transcript-usage` is pinned by test/model/reduce.test.mjs lines 159, 160, 642). Agent.byModel is NOT in the contract: the fixer round adds it to the Run (additive, header comment of src/model/reduce.mjs) because the agent cost needs the models of the counted messages (Trap 4); the orchestrator adds the line to section 2, and the node note says so.
- Contract section 4: GET /api/prices gives { source: "openrouter", url, fetchedAt, models: { [id]: { input, output, cacheRead?, cacheWrite? } } } "in USD per token", "fetched by the server on the first request, kept in memory for one hour, timeout 5 s, sends no user data (a plain GET of the public list). Failure or --offline -> 503 { error } with the reason"; matching a model id is "inferred (method names the rule); no match -> cost unknown for that model".
- AGENTS.md: "Never invent data" (unknown with a reason, inferred with a method); "Do not add handling for formats not observed"; read-only; Node >= 20, zero dependencies; write only owned files. Universal: no model name, price or role hard-coded in src/web/bin; test/integration/universal.test.mjs scans code lines for /\bcodex\b/i, so page text must say "other engines", never name one.

## Traps
1. Model: dedup in collect() by data.messageId, last record by prov.line (not by arrival: a rewritten earlier line arrives late); test with events applied in reverse order. A record with no messageId counts once on its own and the method says how many did. A key missing from a record adds nothing (never NaN). Usage is `inferred`, never `final`, even with a final file. Two unknown reasons: no transcript seen, and transcript seen but no record with usage. totals.usage method says "k of n agents" like totals.tokens. Both usage methods say the sum is over records the source delivers (Measured, the bullet on records the source drops). A message with no model id is in usage but not in byModel and the method says so. Agent.byModel is the agent's usage split by the model of each counted message (inferred, method "sum by transcript model" plus the same no-model note; unknown with the reason of usage, or "no transcript record with usage names its model"; listed in `unknowns` as agents.<id>.byModel; values are copies, the Run shares nothing with the sums). Sum of an agent's byModel = its usage; sum of totals.byModel = totals.usage = sum of agents (all three except messages with no model id).
2. byModel keys (Agent.byModel and totals.byModel) and the prices `models` map are file and network data: `__proto__` and `constructor` must be keys (defineProperty or null prototype, as agents already do); test both.
3. Server: GET only, exactly /api/prices (HEAD, /api/prices/x, other methods start no fetch); the Host check applies. One in-flight promise shared by concurrent requests, entry deleted when it settles (also on rejection); success kept 3,600,000 ms by an injected clock (no timer for expiry); failure is not kept and an expired list is not served after a failed refetch (contract: failure -> 503). fetchedAt is ms since epoch like every other time. The 5 s timeout is an AbortController whose timer is cleared when the fetch settles, unref'd, and aborted on server close; a client that leaves does not abort the shared fetch; do not write to a destroyed response; no per-request listener left. Call fetch(url, { signal }) with no headers, no credentials, no query. Keep only entries with a string id and finite prompt and completion (a bad price leaves the key out, never 0); cacheRead from input_cache_read, cacheWrite from input_cache_write, each only when present. Reasons are one line (offline, timeout after 5 s, HTTP <status>, answer is not a model list), never the upstream body. Test hooks (fetch function, clock, timeout ms) are createServer options, not flags. --offline: a boolean flag in parseArgv and usage(), 503 { error: "offline" } and the fetch function never called; no integration test calls /api/prices without --offline.
4. Cost (pure function in web/lib.js): input*prompt + output*completion + cacheRead*input_cache_read + cacheWrite*input_cache_write; never add cacheRead to input. A part with 0 tokens is 0 whatever the price; a part with tokens and no price makes the cost unknown and names the part; a model with all-zero usage (`<synthetic>`) is skipped; a nonzero model with no match makes the run cost "cost unknown: <models>", never a partial sum shown as the total. Run cost uses totals.byModel; agent cost uses Agent.byModel, the models of the counted messages, and never Agent.model (the final file's or the last record's model: it can be `claude-opus-4-8[1m]`, which has no OpenRouter id, or `<synthetic>`, a zero-usage placeholder, so it is not the model of the tokens); a model of the split with tokens and no match gives unknown naming it, never the run's other models; an agent with usage but no byModel (no message names its model) is unknown with that reason and needs no price list; a Run without Agent.byModel gives "the agent has no usage by model". A split that is all zero costs 0 (method "no model has tokens"). The cost is a Fact built in the page, inferred, method naming the OpenRouter id, base prices (overrides not applied), 5-minute cache write rate, and the limit of the usage it is made of (tokens of the records the source delivers only).
5. Web: request /api/prices once per page, only when a cost is first shown (an ended run's report card with totals.byModel, or an open drawer of an agent with Agent.byModel); a run without usage, the list and the page load never request it; a failure is remembered (no retry timer), shown as "cost unknown: <reason>"; while it is out the line says loading. Rows are keyed cells (report card lists.report.sync, drawer dt/dd keyed): a snapshot patches only the changed text node. Reasons, model ids and OpenRouter ids go through esc() or textContent. Static sentence for other engines, no engine named: "Tokens and cost cover Claude Code agents only; other engines called from an agent are not in Claude Code files and are not counted."
6. Help (4a): the --since line is rewritten to the new meaning (every run is listed; --since <hours> chooses which runs are loaded at start; default 24; Infinity = all; not used by --replay), never appended to; a usage error prints usage() without HELP_NOTE, so the line stands alone. HELP_NOTE keeps only what the line lacks (an older run is read from journal, final file and script and loaded when opened); rewrite the bin comments at lines 5, 25 and 51-53 too (grep -rn -e '--since' src bin web). docs/plugin-stage-draft.md lines 20 and 34 still say the old meaning: not yours, list them in the note.
7. Run list (4b): the summary must equal what summaryOf(getRun(id)) gives, field for field. Its status depends on the clock (stale flip and the silence text in the reason): reuse the rule of cacheHolds/staleAt, test with an injected clock past staleMs. Rebuild a summary only for a run that got events; a test counts builds through a hook on createStore (not by timing). Compare equality over every fixture run and every local run, read-only.
